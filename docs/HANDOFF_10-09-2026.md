## 1) 401 do PerformanceLab — RESOLVIDO

- **Sintoma**: desde ~09h30 BRT de 08/09 a API `pwbi` do PL respondia
  `401 {"status":false,"error":"Unauthorized"}` no primeiro endpoint (`local`)
  — cron e botão "Atualizar agora" falhavam igual; banner amarelo na página `/bi`.
- **Diagnóstico**: a API do PL estava no ar (testada com curl — 401 idêntico
  para credencial falsa). Código da function íntegro. A recusa era de credencial.
- **Causa raiz**: a senha da conta `plena.powerbi` do PerformanceLab foi trocada
  (confirmado pela Elaine, que participou da sessão).
- **Correção**: secret `PLAB_SENHA` atualizado no Supabase pela Management API
  via o novo script **`scripts/atualizar-senha-plab.ps1`** — ele pede a senha na
  tela (não passa pelo chat nem fica em arquivo), grava o secret e dispara um
  sync de teste com a chave do cron (lida de `cron.job`). **Se a senha for
  trocada de novo, é só rodar esse script.** Atenção: manter o script em ASCII
  puro — acento/em-dash em .ps1 sem BOM quebra o parser do Windows PowerShell
  5.1 (primeira versão do script morreu nisso).
- **Validação**: sync de teste em 10/09 ok na 1ª tentativa —
  `{ok:true, locais:76, checklists:570, coletas:667, eventos:238, analises:289,
  removidos:20}`. O banner amarelo some sozinho na próxima carga da página.

## 2) Sync automático reduzido para 1x ao dia (decisão da gestão)

- Como o botão "Atualizar agora" agora funciona (CORS corrigido em 08/09), a
  gestão optou por **1 execução automática às 05h00 BRT**, com execuções
  manuais cobrindo o resto do dia.
- Feito via Management API: `cron.alter_job(1, schedule := '0 8 * * *')` e
  `cron.unschedule` dos jobs 2–5 (`sync-performancelab-meio-dia`, `-06h`,
  `-07h30`, `-15h`). Confirmado: só restou o job 1 (`sync-performancelab-diario`,
  `0 8 * * *` UTC, ativo).
- **Ressalva registrada**: a API do PL não é tempo real — o dia anterior só é
  publicado em algum momento da manhã (em 04/09, às 03h00 ainda não existia; às
  09h05 sim). Se o sync das 05h00 rodar antes da publicação, usar o botão mais
  tarde; se virar rotina, recolocar um 2º horário no fim da manhã.
